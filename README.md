# rivlap.app

The public website for RivLap: the home page, Privacy Policy and Terms of Service. Plain HTML and
CSS, published with GitHub Pages at https://rivlap.app (the `CNAME` file sets the domain).

The app links to https://rivlap.app/terms and https://rivlap.app/privacy, so keep those paths.
When the documents change, update the "Draft version" line on each page and the matching
TERMS_VERSION in the app (which must also be added on the server first).
